Linux-System-Administration-Security-Lab

Practical Linux System Administration and Security Lab covering users, permissions, networking, SSH, system services, security checks, system resources, and troubleshooting.

About the Project

This repository contains a practical Linux System Administration and Security Lab performed on Kali Linux.

The project focuses on developing practical skills in Linux administration, networking, SSH, security checks, system monitoring, and troubleshooting.

The work documented in this repository is based on practical exercises, real commands, results, and screenshots collected during the lab.

Project Objectives
	•	Practice Linux system administration
	•	Manage users and groups
	•	Configure ownership and permissions
	•	Test user access
	•	Inspect network configuration and connectivity
	•	Manage and test SSH services
	•	Inspect firewall configuration
	•	Perform basic security checks
	•	Monitor system resources
	•	Practice troubleshooting
	•	Document practical work using GitHub

Project Phases

Phase 1 — Linux Users, Groups & Permissions

Created users and groups, configured the company directory structure under /opt/company, applied ownership and permissions, and tested user access.

Main topics: users, groups, useradd, usermod, groupadd, chown, chmod, Setgid, and access permissions.

Phase 2 — Network Configuration & Connectivity

Inspected network interfaces, routing, DNS configuration, and tested network connectivity using ping and curl.

Main topics: network interfaces, IPv4, routing, gateway, DNS, connectivity testing, and HTTP/HTTPS.

Phase 3 — SSH Service & Remote Access

Installed, enabled, managed, and tested the OpenSSH service on Kali Linux.

Main topics: OpenSSH, systemctl, SSH service management, local SSH connection, SSH configuration, and port 22.

Phase 4 — Firewall & Security Rules

Inspected the iptables firewall configuration and reviewed the default firewall policies.

Main topics: iptables, INPUT, FORWARD, OUTPUT, firewall policies, and packet/byte counters.

Phase 5 — Linux Security Checks

Performed basic security checks including SSH configuration, running services, permissions, world-writable files, and user group membership.

Main topics: SSH security, services, permissions, security checks, and troubleshooting.

Phase 6 — System Resources & Troubleshooting

Checked disk space, memory usage, swap, system uptime, and system load.

Main topics: df, free, uptime, disk usage, RAM, swap, and system monitoring.

Phase 7 — Documentation & Final Check

Reviewed and organized the complete practical work and documented the project as a GitHub portfolio.
