Phase 6 — System Resources & Troubleshooting

Objective

The objective of this phase was to inspect the system resources of Kali Linux and check the current disk space, memory usage, and system load.

The practical work was performed on Kali Linux.

Disk Space

Disk usage was checked using:

df -h

The main system partition was:
	•	Device: /dev/sda1
	•	Total size: 79G
	•	Used: 16G
	•	Available: 59G
	•	Usage: 22%

Memory Usage

Memory usage was checked using:

free -h

The system showed:
	•	Total RAM: 1.9Gi
	•	Used: 857Mi
	•	Free: 254Mi
	•	Available: 1.1Gi
	•	Swap: 953Mi

System Uptime and Load

System uptime and load were checked using:

uptime

The system had been running for approximately 2 hours and 35 minutes.

The load averages were approximately:

0.36 0.30 0.30
